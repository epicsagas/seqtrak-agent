# CLI 상세 가이드 (`st`)

[English](CLI.md) | 한국어

Yamaha SEQTRAK을 USB MIDI로 제어하고 패턴을 녹음하는 `st` CLI의 전체 명령어 레퍼런스입니다. 최초 장비 설정과 개발 환경 준비는 [개발자 퀵스타트](QUICKSTART.ko.md) ([English](QUICKSTART.md))를 참고하세요.

## 전역 옵션

전역 옵션은 서브커맨드 앞에 위치합니다:

```bash
st [--device <0-15>] [--port <INDEX>] [--json] <SUBCOMMAND>
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--device <N>` | `0` | Yamaha SysEx 디바이스 번호 (`0`부터 `15`, SysEx 헤더의 `10`부터 `1F`에 대응) |
| `--port <INDEX>` | 자동 선택 | 여러 MIDI 인터페이스가 연결된 경우 사용할 입출력 포트 인덱스 지정 |
| `--json` | `false` | 스크립트 연동용 단일 행 JSON 포맷으로 출력 |

## 트랙 이름 (`<TRACK>`)

트랙을 지정하는 모든 명령어는 아래 11개 고정 트랙 이름을 사용합니다:

| 트랙 이름 | MIDI 채널 (1-based) | 파트 인덱스 (16진수 `p`) | 사운드 엔진 |
|---|---|---|---|
| `kick` | 1 | `0` | 드럼 (AWM2) |
| `snare` | 2 | `1` | 드럼 (AWM2) |
| `clap` | 3 | `2` | 드럼 (AWM2) |
| `hat1` | 4 | `3` | 드럼 (AWM2) |
| `hat2` | 5 | `4` | 드럼 (AWM2) |
| `perc1` | 6 | `5` | 드럼 (AWM2) |
| `perc2` | 7 | `6` | 드럼 (AWM2) |
| `synth1` | 8 | `7` | AWM2 폴리 신스 |
| `synth2` | 9 | `8` | AWM2 폴리 신스 |
| `dx` | 10 | `9` | 4오퍼레이터 FM 신스 |
| `sampler` | 11 | `A` (10) | 7슬롯 유저 샘플러 |

## 서브커맨드 상세

### 1. 연결 확인 및 모니터링

#### `st list`

시스템에 연결된 MIDI 출력 및 입력 포트 목록을 출력합니다.

```bash
st list
st --json list
```

#### `st identity`

Universal Device Inquiry(`F0 7E 7F 06 01 F7`)를 전송해 장비 식별 코드와 펌웨어 버전(OS 2.00 기준 `2.0`)을 확인합니다.

```bash
st identity
```

#### `st monitor`

장비에서 들어오는 MIDI 이벤트를 실시간으로 출력합니다. 기본적으로 타이밍 클럭(`0xF8`)과 액티브 센싱(`0xFE`)은 숨기며, `--clock`을 붙이면 함께 출력합니다.

```bash
st monitor --timeout 5          # 5초 동안 수신 후 종료
st monitor --timeout 2 --clock  # 0xF8 클럭 바이트까지 포함해 확인
```

### 2. 노트 발음, 컨트롤 체인지(CC), 프로젝트 및 음색 로드

#### `st note`

지정한 트랙으로 `Note On`을 보내고 `--dur` 밀리초 동안 유지한 뒤 `Note Off`를 전송합니다.

```bash
st note -c kick -n 36
st note -c synth1 -n 60 -v 110 -d 500
```

- `-c, --track <TRACK>`: 대상 트랙 (`kick`부터 `sampler`).
- `-n, --note <0-127>`: MIDI 노트 번호 (드럼 트랙은 번호에 상관없이 트리거되며, 샘플러는 `60`부터 `66`이 7개 샘플 슬롯에 대응).
- `-v, --vel <1-127>`: 벨로시티 (기본값: `100`).
- `-d, --dur <MS>`: 노트 유지 시간(밀리초, 기본값: `200`).

#### `st cc`

지정한 트랙 채널로 컨트롤 체인지(CC)를 전송합니다. CC 이름 또는 번호(`0`부터 `127`)를 모두 사용할 수 있습니다.

```bash
st cc -c synth1 -n volume -v 100
st cc -c dx -n fm_mod_amount -v 90
st cc -c kick -n mute -v 127    # 킥 뮤트 (0 = 해제, 64 이상 = 뮤트)
```

지원하는 29개 전체 CC 이름은 아래 [CC 이름 표](#cc-이름-표)를 참고하세요.

#### `st load`

장비의 프로젝트 `1`부터 `8`을 로드합니다(채널 1에 Bank Select `MSB=64, LSB=0` + Program Change 전송). 프로젝트를 전환할 때 직전 프로젝트 버퍼의 변경 사항은 장비에 자동으로 저장됩니다.

```bash
st load 1
st load 4
```

#### `st pc`

선택한 트랙에 뱅크 셀렉트(`CC 0` MSB, `CC 32` LSB)와 프로그램 체인지(`1`부터 `128`)를 전송해 음색이나 샘플 요소를 바꿉니다.

```bash
st pc -c synth1 -m 63 -l 1 -p 12   # 카테고리 뱅크에서 신스 음색 로드
st pc -c kick -m 32 -l 0 -p 5      # 킥 음색 프리셋 변경
```

| 대상 | MSB (`-m`) | LSB (`-l`) | 프로그램 (`-p`) |
|---|---|---|---|
| 프로젝트 (1부터 8) | `64` | `0` | `1`부터 `8` |
| 트랙 사운드 (음색) | `63` | `0`부터 `16` (카테고리) | `1`부터 `128` |
| 샘플러 엘리먼트 | `62` | `0`부터 `1` | `1`부터 `128` |
| 드럼 킷 / 파츠 | `32`부터 `38` | `0`부터 `1` | `1`부터 `128` |

### 3. SysEx 파라미터, 벌크 덤프, 스냅샷

#### `st param`

Yamaha SEQTRAK Parameter Change SysEx(`F0 43 1n 7F 1C 0C ah am al dd... F7`)를 조립해 전송합니다. 주소 바이트는 `:`, `.`, 또는 공백으로 구분할 수 있습니다.

```bash
st param 00:00:10 01         # USB MIDI SysEx 송신 스위치 켜기
st param 30:50:0F 02         # 킥(파트 0)을 패턴 3으로 전환 (0-based: 00..05)
st param 30:57:16 00 20      # synth1(파트 7) 패턴 길이를 32스텝으로 설정
```

#### `st get`

Parameter Request(`F0 43 3n 7F 1C 0C ah am al F7`)를 보내 단일 파라미터 값을 읽어 옵니다. 사전에 `st param 00:00:10 01`이 켜져 있어야 합니다.

```bash
st get 00:7F:00              # 포맷 버전 조회
st get 30:50:0F              # 킥 트랙의 현재 패턴 인덱스(00..05) 조회
```

#### `st dump`

Bulk Dump Request(`F0 43 2n 7F 1C 0C ah am al F7`)를 보내 다중 패킷 응답을 이어 붙이고 체크섬을 검증한 뒤, 페이로드 16진수를 표준 출력이나 파일로 저장합니다.

```bash
st dump 30:41:00                        # Send Reverb 블록 덤프
st dump 11:00:00 -o project.hex -t 15   # 전체 벌크 덤프를 파일로 저장
```

#### `st bulk`

벌크 덤프 블록을 장비로 되돌려 보냅니다. 입력 파일은 `st dump -o`가 저장한 페이로드 16진수(데이터 바이트만)이며, 이 명령이 장비가 수신하도록 문서화된 벌크 덤프 프레임으로 다시 조립합니다. 시스템 블록으로 실기 검증 완료: 덤프, 동일 페이로드 재기입, 재덤프 결과가 바이트 단위로 일치합니다.

```bash
st dump 11:00:00 -o backup.hex -t 15    # 프로젝트 읽기
st bulk 11:00:00 backup.hex             # 되돌려 보내기 (검증됨: 덤프-재기입-재덤프 일치)
```

#### `st sysex`

임의의 원시 SysEx 16진수 바이트(`F0 ... F7`)를 전송하고 `--wait` 밀리초(기본값: `500`) 동안 수신된 SysEx 응답을 출력합니다.

```bash
st sysex "F0 7E 7F 06 01 F7" --wait 500
```

#### `st snapshot`

프로젝트(`1`부터 `8`, 또는 로드 없이 수신만 하려면 `0`)를 로드하면서 장비가 뱉어내는 파라미터 변경 스트림을 탭 구분 형식(`hh:mm:ll<TAB>hex`)으로 캡처합니다.

```bash
st snapshot --project 1 --seconds 5 > project1.tsv
st snapshot --project 0 --seconds 3     # 재로드 없이 본체 노브 조작만 캡처
```

### 4. 트랜스포트 및 스텝 패턴 녹음

#### `st transport`

시퀀서 재생/정지 및 외부 클럭 전송을 제어합니다. 장비의 MIDI Sync 설정이 `External` 또는 `Auto`여야 합니다.

```bash
st transport start                      # MIDI Start (0xFA) 전송
st transport stop                       # MIDI Stop (0xFC) 전송
st transport clock --bpm 124 --seconds 8
```

#### `st rec-steps`

장비가 내보내는 96 PPQ MIDI 클럭(16분음표당 6클럭)에 동기화해 단일 노트의 16분음표 스텝 패턴을 장비 실시간 녹음기에 기록합니다. 실행 전 본체 패널의 물리 `REC` 버튼을 먼저 켜 두어야 합니다.

```bash
# 여러 트랙 연속 녹음: 마지막 테이크 전까지 --keep-playing 사용
st rec-steps kick   --steps 1,5,9,13 --keep-playing
st rec-steps snare  --steps 5,13 --vel 95 --keep-playing
st rec-steps hat1   --steps 1,3,5,7,9,11,13,15 --vel 75
```

- `--steps <LIST>`: 쉼표로 구분한 1-based 16분음표 스텝 번호 (`1`부터 `16`은 1마디, 최대 8마디 `128`).
- `--note <0-127>`: MIDI 노트 번호 (기본값: `60`).
- `--vel <1-127>`: 벨로시티 (기본값: `100`).
- `--bars <1-8>`: 실행할 마디 수 (기본값: `1`).
- `--gate <TICKS>`: 16분음표 단위 노트 길이 (기본값: `1`).
- `--keep-playing`: 테이크가 끝나도 `Stop`(`0xFC`)을 보내지 않아 다음 트랙 녹음을 위해 `REC` 대기 상태를 유지합니다.

#### `st seq`

정지 상태에서 단일 `Start`로 여러 `(스텝, 노트)` 이벤트를 한 번의 스윕으로 기록합니다. 멜로디, 베이스라인, 코드 진행처럼 서로 다른 음정을 한 트랙에 녹음할 때 여러 번 재시작하면서 생기는 클럭 어긋남을 방지합니다.

```bash
# 1마디 synth1 베이스라인을 단일 스윕으로 녹음
st seq synth1 --events 1:48,5:48,7:55,9:48,13:53,15:55 --vel 100 --bars 1 --gate 2
```

- `--events <STEP:NOTE,...>`: 쉼표로 구분한 `스텝:노트` 쌍 (`1`-based 스텝). 같은 스텝에 여러 노트를 적으면 코드로 동시 발음됩니다(예: `1:60,1:64,1:67`).
- `--vel <1-127>`: 벨로시티 (기본값: `100`).
- `--bars <1-8>`: 실행할 마디 수 (기본값: `1`).
- `--gate <TICKS>`: 16분음표 단위 노트 길이 (기본값: `1`).
- `--keep-playing`: 스윕 종료 후에도 재생 및 `REC` 상태를 유지합니다.
- `--clock-offset <0-5>`: 각 16분음표 경계에서 `0`부터 `5` 클럭만큼 뒤로 밀어 노트를 발사합니다 (기본값: `0`).

### 5. 웹 GUI 서버

#### `st serve`

로컬 웹 GUI 정적 파일(`gui/dist`)과 `/api/*` 엔드포인트를 `http://127.0.0.1:8787`에서 서빙합니다.

```bash
st serve
```

## 자주 쓰는 SysEx 주소

아래 표에서 `p`는 0-based 파트 인덱스 16진수(`kick` = `0` .. `sampler` = `A`)입니다:

| 주소 | 데이터 바이트 | 의미 |
|---|---|---|
| `00:00:10` | `00` / `01` | USB MIDI SysEx 송신 스위치 (`01` = 켜기) |
| `00:00:26` | `00`..`7F` | 메트로놈 음량 (`00` = 무음) |
| `30:5p:0F` | `00`..`05` | 파트 `p`의 패턴 `1`부터 `6` 선택 |
| `30:5p:16` | `<MSB> <LSB>` | 패턴 스텝 길이 (`00 10` = 16, `00 20` = 32, `00 40` = 64, `01 00` = 128) |
| `30:41:00` | `MSB LSB` | Send Reverb 타입 |
| `30:42:00` | `MSB LSB` | Send Delay 타입 |
| `30:43:00` | `MSB LSB` | Master Effect 타입 (카테고리 `0`-`7`, 프리셋 `0`-`7`) |
| `31:1p:00` | `28`..`58` | 파트 피치 / 옥타브 오프셋 (`40` = 중앙) |
| `31:2p:00` | `MSB LSB` | 트랙 싱글 이펙트(Insertion A) 타입 |
| `31:4p:00` | 9바이트 | 사운드 LFO 블록 (파형, 속도, 깊이, 모듈레이션 대상) |
