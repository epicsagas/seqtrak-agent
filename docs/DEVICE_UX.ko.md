# 하드웨어 판면 UX 명세 (Device Faceplate UX)

[English](DEVICE_UX.md) | 한국어

기준 문서: SEQTRAK 유저 가이드 D0 1.2절(구조) 및 2절(패널 항목 1부터 27), 그리고 OS 2.00 실기 검증 결과입니다. 웹 GUI의 `DEVICE` 뷰를 마우스나 터치로 조작할 때 실제 하드웨어 상판을 만지는 것과 동일하게 동작하도록 설계했습니다.

> **참고:** 웹 GUI는 현재 프로토타입 상태이며 일부 조작이나 하드웨어 상태 반영이 정확히 동작하지 않을 수 있습니다.

## 패널 컨트롤과 MIDI 매핑

| 패널 컨트롤 | 실제 하드웨어 동작 (유저 가이드) | GUI 동작 |
|---|---|---|
| `[VOL+]` / `[VOL-]` (1) | 본체 스피커/헤드폰 모니터 음량 | 화면의 모니터 수치만 변경하며 MIDI 메시지는 보내지 않음 |
| `[DELETE]` (2) | 패턴/프로젝트 삭제 | MIDI로 제공되지 않는 기능(화면에 안내 문구 표시) |
| `[MUTE]` / `[SOLO]` (3/4) | 모드 진입 후 트랙 노브를 눌러 적용 | 동일하게 모드 활성화 후 트랙 노브 클릭 시 CC 23 / CC 24 전송 |
| `[PAGE]` (5) | 드럼 스텝 페이지 1-16 / 17-32 전환 | 2x8 스텝 그리드의 1-16스텝과 17-32스텝 페이지 전환 |
| `[PLAY]` (6) | 프로젝트 재생 및 정지 | MIDI Start/Stop 전송, 본체 PLAY 버튼 조작도 실시간 반영 |
| `[ALL]` 노브 (7) | 11개 전체 트랙의 패턴(1-6) 동시 변경 | 1부터 6까지 단계별로 회전하며 전체 트랙에 SysEx 패턴 선택(`30:5p:0F`) 전송 |
| 트랙 노브 (8) | 돌리면 해당 트랙 패턴(1-6) 변경, 누르면 트랙 선택(정지 중엔 청음) | 동일하게 동작하며, 클릭 시 장비에서 현재 패턴 번호를 SysEx로 읽어와 동기화 |
| 드럼 키 (9) | 선택된 트랙의 16분음표 스텝 켜기/끄기 | GUI 스텝 레이어의 스텝을 토글하며 장비의 96 PPQ MIDI 클럭에 맞춰 발음 |
| `[REC]` 키 (10) | 실시간 녹음 대기 활성화 | GUI 스텝 레이어 녹음을 켜서 재생 중 스케일 키 입력을 현재 스텝에 기록. 본체 REC도 켜져 있으면 동일한 Note On이 장비 패턴 메모리에도 함께 기록됨 |
| 신스 키 (11) | 선택된 신스/샘플러 트랙 스케일 연주 | `[REC]` + 7개 스케일 키(`C4`-`B4`), 즉시 청음하거나 `REC` + 재생 중 스텝에 기록 |
| `[BAR LENGTH]` / `[OCTAVE]` / `[SCALE]` / `[KEY]` / `[REC SAMPLE]` (12-16) | 마디 길이, 옥타브, 스케일, 키, 샘플 녹음 | 판면 뷰에서는 안내 문구 표시(패턴 길이는 CLI/MCP의 SysEx `30:5p:16`으로 제어 가능) |
| 사운드 디자인 노브 (20) | 선택 트랙의 사운드 파라미터 4종 조절 | 컷오프, 레조넌스, 어택, 디케이 오프셋(CC 74/71/73/75) 전송 |
| `[FX]` 노브 (23) | 이펙트 종류 선택 | SysEx `30:43:00`(마스터) 또는 `31:2p:00`(싱글)로 카테고리(MSB 0-7)와 프리셋(LSB 0-7) 변경 |
| `[MASTER/SINGLE]` (24) | 이펙트 적용 범위 고정식 슬라이드 스위치 | 클릭 시 `MST`와 `SINGLE` 사이를 오가는 고정식 슬라이드 스위치 |
| `FX LEVEL` / `HIGH PASS` / `REPEATER` (25) | 터치 퍼포먼스 슬라이더 | 페이지 1: `FX LEVEL`(CC 102/107), 그리고 손을 떼면 0으로 복귀하며 중립값(64)을 보내는 순간 작동식 `HIGH PASS` 및 `REPEATER`. 페이지 2: 할당 파라미터 1/2/3(CC 102-104 또는 107-109) |
| `[CLEAR FX]` (22) | 현재 이펙트 레벨 최소화 | FX 레벨을 0으로 내리고 컷오프와 게이트를 중립값(64)으로 복구 |

## 스텝 레이어와 하드웨어 클럭 동기화

SEQTRAK은 재생 중 96 PPQ(16분음표당 6클럭, MIDI Clock Out 기본값 On)로 MIDI 타이밍 클럭을 내보냅니다. `st serve` 백엔드는 전용 MIDI 입력 연결에서 이 클럭을 받아 16분음표 틱으로 변환하고, 전용 MIDI 출력 연결을 통해 GUI 스텝 레이어의 노트를 발사합니다. 프론트엔드는 120ms 주기로 `GET /api/seq`를 폴링하므로 본체의 물리 PLAY 버튼을 눌러 재생을 시작해도 웹 화면의 재생 헤드와 PLAY 상태가 함께 움직입니다.

GUI 스텝 레이어는 `st serve` 메모리에 유지되므로 장비 내부 패턴 메모리를 건드리지 않습니다. 드럼 스텝은 채널 1부터 7로 노트 60을 보내고, 신스 스텝은 녹음된 음높이를 저장합니다. 반면 트랙 노브를 돌릴 때는 SysEx `30:5p:0F`(패턴 선택, 0부터 5)를 장비로 직접 읽고 씁니다.

## 매뉴얼 대조 및 실기 검증으로 바로잡은 사항

- `MASTER/SINGLE`은 버튼 두 개가 아니라 한쪽 위치가 유지되는 고정식 슬라이드 스위치입니다.
- FX 페이지 1의 `HIGH PASS`와 `REPEATER`는 손을 떼는 순간 효과가 사라지고 0으로 돌아가는 순간 작동식(momentary) 슬라이더이며, 스위치 위치와 무관하게 전체 트랙에 걸립니다.
- 트랙 노브와 `[ALL]` 노브는 볼륨이 아니라 패턴(1부터 6)을 선택합니다. 장비 본체의 노브 감도는 시스템 오프셋 `2F`(Pattern Select Sensitivity)를 따릅니다.
- 16개의 드럼 키는 2x8 스텝 그리드로서 선택된 트랙의 스텝을 켜고 끕니다.
- 신스 키 블록의 첫 번째 키는 `[REC]`이며 나머지 7개 키가 스케일 음표를 연주합니다.
- `[VOL+]`와 `[VOL-]`는 모니터 출력 음량만 조절하며 MIDI CC를 내보내지 않습니다.

## 인터랙션 규칙

- **노브**: 수직 드래그 또는 마우스 휠(`Shift` 조합 시 5단위)로 값을 조절합니다. 패턴 노브는 1부터 6까지 단계별로 움직입니다. 드래그 없이 짧게 클릭(< 150ms)하면 트랙 선택(정지 중엔 청음)이 실행되고, 420ms 이상 길게 누르면 해당 트랙을 뮤트합니다.
- **키**: `pointerdown` 시점에 즉시 반응합니다. 켜진 스텝 셀은 트랙 색상으로 점등되고 현재 재생 위치의 셀은 굵은 테두리로 표시됩니다.
- **터치 슬라이더**: 수직 드래그로 조절하고 더블클릭하면 기본값으로 초기화됩니다. 스프링 슬라이더(페이지 1의 `HIGH PASS`, `REPEATER`)는 손을 떼면 0으로 돌아갑니다.
- **LED 색상 체계**: 하드웨어와 동일하게 노란색은 드럼(트랙 1-7), 시안색은 신스 및 샘플러(트랙 8-11), 주황색은 트랜스포트·`REC`·마스터 컨트롤을 나타냅니다.
- **상태 표시창**: 우측 상단 가상 스크린에 현재 모드, 선택된 트랙, 패턴 번호, FX 페이지, 마지막으로 전송한 파라미터를 표시합니다.

## 렌더링 및 연결 복구

판면 전체는 WebGL 없이 단일 반응형 SVG(`1560x430` viewBox)와 투톤 플랫 셰이딩으로 그려 어떤 배율에서도 선명하고 가볍습니다. `st serve`는 장비가 연결되지 않은 상태에서도 기동하며 2초마다 재연결을 시도하고, 케이블 재연결 후 CoreMIDI 클라이언트가 멈추면 `MIDIRestart`로 복구합니다.
